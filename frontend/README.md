# AI Fashion Agent 프론트엔드 — Step 6 평가 개선

HTML + CSS + JavaScript ES modules 기반입니다. 기존 로그인·프로필·취향·옷장·Google Calendar·5 LOOK 추천·이미지 조회·코디 저장 기능을 사용합니다.

## 이번 변경

- 좋아요·싫어요 버튼의 문구를 선택 전후에도 그대로 유지합니다. 선택한 버튼을 다시 누르면 평가가 해제됩니다.
- 선택 상태는 배경·테두리 및 `aria-pressed`로 표시합니다.
- 평가·저장 처리 안내는 조작한 LOOK에만 표시합니다. 다른 LOOK의 안내를 새 조작의 문구로 바꾸지 않습니다.
- 싫어요 사유를 10개로 늘렸습니다: 색상, 핏, 취향, 너무 격식 있음, 너무 평범함, 너무 캐주얼함, 날씨·계절, 일정·장소, 옷의 조합, 기타.
- `기타 (직접 입력)`은 최대 300자로 작성한 뒤 `사유 저장`을 누릅니다. 사유 없이 싫어요를 남기는 기능도 유지합니다.

## 적용과 실행

**이 버전은 백엔드와 DB 업데이트가 필요합니다.** 압축 묶음의 `README.md`를 읽고 `apply_update.py`로 적용합니다. 프론트엔드만 복사하면 새로운 사유와 기타 내용을 저장할 수 없습니다.

기본 프론트엔드 경로: `$HOME/Documents/ai-fashion-agent-FR/frontend`

```bash
python3 "$HOME/Documents/ai-fashion-agent-FR/frontend/dev_server.py"
```

기존 백엔드도 실행한 상태에서 [http://localhost:5500](http://localhost:5500)에 접속합니다. 새 파일 적용 후에는 **Cmd+Shift+R**로 새로고침합니다. 개발 서버는 `/api/v1/*` 요청을 `http://127.0.0.1:8000`으로 전달합니다.

## 평가·사유·저장 동작

| 조작 | 결과 |
| --- | --- |
| 좋아요 또는 싫어요 선택 | 해당 LOOK의 평가를 변경 |
| 선택된 평가 버튼 다시 누르기 | 평가 해제 |
| 미리 정해진 싫어요 사유 선택 | 즉시 저장 |
| 기타 선택 후 입력 | 해당 LOOK의 초안으로 유지 |
| 기타에서 사유 저장 | 내용 검증 후 서버에 저장 |
| 좋아요로 변경·평가 해제·다른 사유 저장 | 이전 기타 사유 내용 제거 |
| 코디 저장·저장 취소 | 평가와 별개로 저장 목록 변경 |

기타 사유는 앞뒤 공백을 제외해 최대 300자이며 빈 내용을 허용하지 않습니다. 줄바꿈은 허용합니다. 다른 LOOK 조작과 이미지 펼치기는 초안을 지우지 않습니다. 저장하지 않은 초안은 로그아웃·새 추천·브라우저 새로고침 시 사라집니다.

## 데이터 유지 범위

- 평가·사유·기타 내용·저장 상태는 서버에 저장합니다. 같은 추천 ID의 상태를 조회하면 복원됩니다.
- 원본 추천 결과 5개 카드는 화면 메모리에 유지됩니다. 브라우저 새로고침 후 전체 카드를 자동 복구하는 API는 현재 연결되어 있지 않습니다.
- 저장한 코디 목록은 서버에서 다시 조회합니다. 로그아웃은 DB에 저장된 항목을 삭제하지 않습니다.
- 계정이 바뀌면 이전 계정의 개인 화면 상태를 지우고, 뒤늦게 도착한 이전 계정의 응답을 사용하지 않습니다.
- 변경 요청 성공 여부가 불확실하면 서버 상태를 재확인합니다. 확인에 실패하면 재확인 버튼을 사용합니다.

## 이미지와 추천 범위

추천 생성·평가·저장만으로 상품 이미지 검색을 자동 실행하지 않습니다. LOOK의 `이미지 보기`를 눌렀을 때 이미지 API를 요청합니다. LOOK 1~3은 상품 참고 이미지, LOOK 4~5는 등록한 옷장 사진을 사용합니다. 참고 상품 사진은 추천한 색상·핏·종류와 다를 수 있습니다.

이번 업데이트는 평가 UI와 사유 저장을 수정합니다. 새로 입력한 자유 사유를 Qwen이 해석해 추천에 자동 반영하도록 바꾸는 작업은 포함하지 않습니다.

| `js/main.js` | 화면 이동과 계정 연결 |
